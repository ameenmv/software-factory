# B001: Add refund request schema and remaining-amount helper

Feature: `001-partial-refunds`

## Context

Schemas in this package follow `packages/shared/src/order.ts:12`:

```ts
import { z } from 'zod';

export const orderNoteSchema = z.object({
  body: z.string().trim().min(1).max(500),
});
export type OrderNote = z.infer<typeof orderNoteSchema>;
```

Money helpers live in `packages/shared/src/money.ts`; amounts are integer minor units.
Tests use Vitest, see `packages/shared/src/order.test.ts:1` for the import style.

## Steps

1. Create `refund.ts` with `refundRequestSchema` (`amount`: int, positive; `reason`: optional trimmed string, max 200) and its inferred type `RefundRequest`.
2. Add `remainingRefundable(captured: number, refunds: readonly number[]): number` returning `Math.max(0, captured - sum)`.
3. Export both, and the type, from `index.ts` in the existing alphabetical block.
4. Write `refund.test.ts` with one `it` per `done_when` item.

## Pitfalls

- Checklist 5: do not re-implement money formatting; this slice formats nothing.
- `z.number().int().positive()`, not `.min(1)`: the error message must say positive.
